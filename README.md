### Quick Start

1) Fill in the `.env` file.

2) Run the following:

```powershell
git pull
C:\Python310\python.exe -m venv venv
.\venv\Scripts\activate
pip install -r ./requirements.txt

python configure_env.py
python start_websockify.py
npm i
npm run build
npm start
```
