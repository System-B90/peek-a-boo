# PyHiveLMS is published to a small PEP 503 index in System-B90/.github, not to
# PyPI, whose copy stops at 2.1.1. The index is served by GitHub Pages — NOT by
# raw.githubusercontent.com, which cannot back a pip index at all: it 404s the
# directory URL pip requests, and serves index.html as text/plain with nosniff
# so --find-links will not scrape it either.

# Hive and takes setup.py down with it.
